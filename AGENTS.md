# Agent guidelines

This repo is Alexander Widing's personal CV/portfolio site (Astro + TypeScript + Tailwind).

## Writing style

Any human-facing prose in this repo — résumé copy and bullet highlights in
`src/data/resume.json`, page and site content, the README, docs, and commit messages — should
read as if a person wrote it, not as if it were generated. Follow the guide at
[docs/writing-style.md](docs/writing-style.md): be specific over grand, use plain verbs, and
avoid the stock vocabulary and formulaic structures that mark AI writing.

## Git
- Never include `Co-Authored-By` lines in commit messages
